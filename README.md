# GodGreat – Multi-Vendor E-Commerce Platform

## Overview

GodGreat is a multi-vendor e-commerce platform designed to connect customers and vendors through a seamless digital shopping experience.

The platform consists of a Flutter-based customer application, a separate vendor application, and a backend API that facilitates communication and product data exchange between the applications.

Customers can explore product categories, browse available products, and access product information, while vendors can upload and manage their product listings.

## Technology Stack

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Backend:** REST API
- **Architecture:** Client-server architecture
- **API Integration:** HTTP-based communication between applications and backend services

## Core Features

### Customer Application
- User registration and authentication
- Product category and subcategory browsing
- Product discovery and browsing
- Popular product listings
- Product information display

### Vendor Application
- Vendor product uploads
- Product information management
- Product categorization
- Product listing management

### Backend Integration
- REST API communication
- Vendor-to-customer product data exchange
- Dynamic product retrieval and display

## Project Architecture

The platform is organized into three interconnected components:

1. **Customer Application:** Provides the shopping interface for customers.
2. **Vendor Application:** Enables vendors to upload and manage products.
3. **Backend Services:** Handles API requests and facilitates data exchange between applications.
